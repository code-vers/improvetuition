SECTION A · EQUIVALENT FRACTIONS

Find the missing number

Aim: Find an equivalent fraction by scaling top and bottom by the same factorA whole number that divides another exactly, with no remainder. 3 is a factor of 12 because 12 ÷ 3 = 4..

Rule: Multiply (or divide) BOTH the numerator AND the denominator by the same number. Value stays the same.
3/4 = 6/8 = 9/12 = 15/20 = …
Worked example
2/7 = ?/35. Find the numerator.
  1. Denominator goes from 7 to 35: multiply by 5.
  2. Apply to numerator: 2 × 5 = 10.
  3. So 2/7 = 10/35. ✓
SECTION B · ORDERING

Compare fractions

Aim: Decide which of two or three fractions is smallest.

Find a common denominator (the LCMLowest common multiple. The smallest number that is a multiple of both a and b. LCM(4, 6) = 12.). Convert each fraction. Compare numerators.
Worked example
Which is smaller: 2/5 or 1/4?
  1. LCMLowest common multiple. The smallest number that is a multiple of both a and b. LCM(4, 6) = 12.(5, 4) = 20.
  2. 2/5 = 8/20. 1/4 = 5/20.
  3. 5/20 < 8/20, so 1/4 is smaller. ✓
SECTION C · ADD AND SUBTRACT

Add and subtract proper fractions

Aim: Fluent addition and subtraction with different denominators, and with a whole numberA number with no fractional part: 0, 1, 2, 3, 4, … on one side.

Common denominator first. Add or subtract numerators only. Simplify if possible.
For a whole numberA number with no fractional part: 0, 1, 2, 3, 4, …, write it over the denominator: 5 = 15/3.
Watch out

1/3 + 1/6 is NOT 2/9. You can’t just add tops and bottoms. Common denominator first: 1/3 = 2/6, then 2/6 + 1/6 = 3/6 = 1/2.

SECTION D · MIXED NUMBERS

Mixed number arithmetic

Aim: Add and subtract mixed numbers reliably, including the conversion back at the end.

The process:
1. Convert both mixed numbers to improper fractions.
2. Find a common denominator.
3. Add or subtract numerators.
4. Convert the result back to a mixed number.
5. Simplify the fractional part if needed.
Watch out

Don’t try to add the whole parts separately and the fractions separately when subtracting — you’ll often need to “borrow” from the whole part. The improper-fraction route avoids this entirely.

SECTION E · FRACTION OF A NUMBER

Find a fraction of a number

Aim: Calculate “X/Y of N” with no calculator.

Two steps:
1. Divide N by the denominator Y.
2. Multiply the result by the numerator X.
So 3/4 of 20 = (20 ÷ 4) × 3 = 5 × 3 = 15.
Worked example
Find 5/6 of 42.
  1. Divide by 6: 42 ÷ 6 = 7.
  2. Multiply by 5: 7 × 5 = 35. ✓
VOCABULARY
Numerator
The top number of a fraction.
Denominator
The bottom number of a fraction.
Equivalent fraction
A fraction with a different look but the same value.
Lowest terms
Top and bottom share no common factor other than 1.
Improper fraction
Top is bigger than (or equal to) the bottom. 7/3.
Mixed number
Whole number plus a proper fraction. 2 1/3.
Common denominator
The LCM of two or more denominators. Used to compare or add/subtract fractions.

Recap

  • Equivalent: multiply top and bottom by the same number.
  • Compare: common denominator, then compare numerators.
  • Add/subtract: common denominator, then numerators only.
  • Mixed numbers: convert to improper first.
  • Fraction of: divide by denominator, multiply by numerator.

Your answer: (4 marks)

  2. Add: 9/4 + 6/4 = 15/4.
  3. Convert to mixed: 15 ÷ 4 = 3 remainderWhat’s left over after dividing. 7 ÷ 2 = 3 with remainder 1. 3. So 3 3/4.
