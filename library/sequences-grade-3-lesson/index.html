Sequences

Spot the rule. Apply it step by step. One small step at a time.

The six facts you need

Every sequences question uses one of these. You don't need to remember anything else.

1 · SequenceA list of numbers that follow a rule. Each number is a term.
2 · Find the ruleLook at how each term changes — add, subtract, multiply or divide.
3 · LinearAdd or subtract the same number each time. The number is the common difference.
4 · GeometricMultiply or divide by the same number each time.
5 · Special sequencesSquares (1, 4, 9, 16…), triangulars (1, 3, 6, 10…), Fibonacci (1, 1, 2, 3, 5, 8…).
6 · Find a later termExtend the sequence step by step. Don't try to jump.

Worked example 1 — continue a linear sequence

Find the next term in 4, 7, 10, 13, …

  1. Read it. A sequence of four numbers. We need the fifth one.
  2. Spot the rule. 4 → 7 is +3. 7 → 10 is +3. 10 → 13 is +3.
  3. Name the rule. The rule is +3 each time. This is a linear sequence with common difference 3.
  4. Use the rule. Add 3 to the last term: 13 + 3 = 16.
Answer: 16
Watch outAlways check more than one gap. If the differences are not the same, it might not be a linear sequence.

Worked example 2 — a sequence going DOWN

Find the next term in 20, 17, 14, 11, …

  1. Read it. A sequence going DOWN. We need the next term.
  2. Spot the rule. 20 → 17 is −3. 17 → 14 is −3. 14 → 11 is −3.
  3. Name the rule. The rule is −3 each time. Still linear — the common difference is just negative.
  4. Use the rule. 11 − 3 = 8.
Answer: 8
Watch outDecreasing sequences are still linear. Watch the minus sign — write it down so you do not lose it.

Worked example 3 — state the rule

What is the term-to-term rule for 5, 9, 13, 17, …?

  1. Read it. We need to describe the rule. Not the next term — the rule itself.
  2. Spot the change. 5 → 9 is +4. 9 → 13 is +4. 13 → 17 is +4.
  3. Write the rule. Each term is 4 more than the one before.
Answer: Add 4 each time. (Common difference = 4.)
Watch outStating the rule means saying how it changes — not predicting future terms. The answer is a description like "add 4", not a number like "21".

Worked example 4 — find a later term by extending

The first three terms of a linear sequence are 3, 7, 11, …. Find the 8th term.

  1. Read it. We need the 8th term. We have only 3 terms. We need to extend.
  2. Spot the rule. The common difference is +4.
  3. Extend step by step. Term 4: 11+4 = 15. Term 5: 15+4 = 19. Term 6: 19+4 = 23. Term 7: 23+4 = 27. Term 8: 27+4 = 31.
Answer: 31
Watch outWrite each step on its own line. Skipping steps in your head causes mistakes. Five small adds beats one big mental jump.

Worked example 5 — a sequence that MULTIPLIES

Find the next term in 2, 6, 18, 54, …

  1. Read it. A sequence that gets bigger fast. Look at how.
  2. Spot the rule. 6 ÷ 2 = 3. 18 ÷ 6 = 3. 54 ÷ 18 = 3.
  3. Name the rule. The rule is ×3 each time. This is a geometric sequence.
  4. Use the rule. 54 × 3 = 162.
Answer: 162
Watch outWhen a sequence grows fast, try dividing one term by the previous one. If you keep getting the same answer, it is geometric.

Worked example 6 — a geometric sequence going DOWN

Find the next term in 80, 40, 20, 10, …

  1. Read it. A sequence halving each time. Find the next term.
  2. Spot the rule. 80 → 40 is ÷2. 40 → 20 is ÷2. 20 → 10 is ÷2.
  3. Name the rule. The rule is ÷2 each time. Geometric.
  4. Use the rule. 10 ÷ 2 = 5.
Answer: 5
Watch outDividing each time IS geometric. Some pupils call this "linear because it goes down" — that is wrong. Linear subtracts the same amount; geometric divides by the same amount.

Worked example 7 — the square numbers

The square numbers begin 1, 4, 9, 16, 25, …. Find the 7th square number.

  1. Read it. The square numbers come from arranging dots in a square.
  2. Spot the pattern. 1 = 1×1. 4 = 2×2. 9 = 3×3. 16 = 4×4. The nth square number is n × n.
  3. Use the rule. The 7th square number is 7 × 7 = 49.
Answer: 49
Watch outThe differences between square numbers GROW: +3, +5, +7, +9. So square numbers are NOT linear.

Worked example 8 — the triangular numbers

The triangular numbers begin 1, 3, 6, 10, …. Find the next one.

  1. Read it. Triangular numbers come from arranging dots in a triangle.
  2. Spot the pattern. 1 → 3 is +2. 3 → 6 is +3. 6 → 10 is +4. The gap goes up by 1 each time.
  3. Use the rule. Next gap is +5. Next term: 10 + 5 = 15.
Answer: 15
Watch outTriangular numbers are NOT linear. The gap between terms keeps growing. Always check more than one gap before deciding the rule.
